# Spec Delta: public-site-isolation（外网产物与本地环境隔离）

## Purpose

确保公网发布产物只包含外部访客需要的内容：不含仅本地可用的功能入口、本地环境文案、本地绝对路径或构建期工具，使外网站点对任何访客都是自洽可用的。

## ADDED Requirements

### Requirement: 外网不展示本地专属功能入口与文案

静态（外网）模式下，页面 MUST NOT 展示仅本地服务可用的功能入口（如"排除文件夹设置"依赖本地 `/api/ignore-rules`、"一键同步更新"若定位为本地全量扫描），也 MUST NOT 展示引用本地地址的说明文案（如 `http://127.0.0.1:8088`）。本地模式下这些入口与文案 MUST 保持原有可用性。

#### Scenario: 外部访客打开外网站点
- **WHEN** 访客访问 https://asset-9n2.pages.dev/
- **THEN** 页面上看不到任何仅本地可用的配置入口，也看不到任何指向 127.0.0.1/localhost 的提示文案

#### Scenario: 本机访问本地服务
- **WHEN** 在本机打开 http://127.0.0.1:8000/
- **THEN** 排除文件夹设置等本地专属入口与文案照常显示并可用

### Requirement: 发布产物不含本地路径与构建工具

公网仓库与发布产物 MUST NOT 包含本地绝对路径（如 `G:\Simreay\output`、`abs_path` 字段）或构建期工具与中转产物（如 ffmpeg 可执行文件、转码临时文件、本地缓存）。`.gitignore` MUST 覆盖工具目录与中转产物，且发布脚本的 `git add -A` 不得因此把它们纳入提交。

#### Scenario: 检查已发布数据
- **WHEN** 检查线上 `data/assets.json`
- **THEN** 其中不含任何本地绝对路径字段

#### Scenario: 引入本地构建工具后执行发布
- **WHEN** 本机安装了转码工具并运行发布脚本
- **THEN** 工具与临时产物不会被提交到公网仓库

### Requirement: 构建期依赖具备可移植的自动探测

转码等构建期步骤使用的工具（如 ffmpeg）MUST 通过自动探测获得（环境变量、PATH、常见安装位置），MUST NOT 硬编码某台机器的专属安装路径；探测失败时 MUST 跳过该步骤并给出明确提示，MUST NOT 中断发布流程。

#### Scenario: 另一台机器执行发布
- **WHEN** 在未安装转码工具的机器上运行发布流程
- **THEN** 流程继续正常发布（跳过转码），并输出清晰的缺失提示与安装指引
